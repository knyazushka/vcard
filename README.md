# vcard

Виртуальная визитка сотрудника: страница по адресу `domain.com/employee/{slug}`
и скачиваемая PNG-карточка на её основе.

Go · PostgreSQL · REST (contract-first, OpenAPI → ogen) · двенадцать факторов.
Прод — Docker Compose на VPS: Caddy, S3, Prometheus и Grafana; выкатка —
GitHub Actions.

## Что умеет

**Компания.** Заводится self-service; создатель становится администратором.
Реквизиты, логотип, справочники должностей и тегов, состав сотрудников.

**Приглашения.** Единственный способ попасть в компанию: администратор шлёт
письмо, приглашённый регистрируется по ссылке и сразу получает черновик визитки.

**Визитка.** Имя, фотография с кадрированием, должность из справочника или своя,
до трёх тегов, «Обо мне» с очисткой разметки, телефон, Telegram и WhatsApp,
реквизиты компании по желанию сотрудника. Свой адрес, который можно поменять
на любой свободный.

**Карточка.** PNG и SVG, отрисованные кодом из одной раскладки. Первая
отрисовка — сотни миллисекунд, дальше отдаётся из кэша.

## Быстрый старт

```bash
make db-up && make migrate-up
cp .env.example .env
make run
```

`make run` экспортирует `.env` в окружение и запускает сервис. Загрузчика
`.env` внутри приложения нет: конфигурация приходит только из окружения
(фактор III), и `go run ./cmd/api` без экспорта переменных упадёт на
проверке обязательных полей — это не поломка, а ожидаемое поведение.

API — `:8080`, пробы и метрики — `:9090`, пойманные письма —
<http://localhost:8025>.

## Прод и прод-стенд

Push в `main` → проверки → образ в GHCR → выкатка на сервер по SSH.
Настройки прода — в окружении `production` в GitHub. Что завести в облаке
и в каком порядке — «Первая выкатка» в [эксплуатации](docs/operations.md).

До покупки чего-либо прод целиком проверяется локально — из тех же файлов,
что уедут на сервер, с контейнерами вместо управляемых сервисов:

```bash
make stand-up       # образ, миграции, Caddy, MinIO, Prometheus, Grafana
make stand-smoke    # сквозная проверка через HTTPS
make stand-down
```

Grafana стенда — <http://localhost:3030> (`admin` / `local-admin`).
Нужен Docker Compose 2.30+.

## Отличия от исходного ТЗ

Приняты осознанно, каждое разобрано в [решениях](docs/decisions.md):

- **Go вместо Laravel**, **REST вместо GraphQL**;
- **PNG, отрисованный кодом**, вместо JPEG из свёрстанного фронтом HTML;
- **администратор у каждой компании**, а не один глобальный — из-за этого
  сотрудник не выбирает компанию из списка, а попадает в неё по приглашению.

## Незакрытые долги

Не «когда-нибудь», а список того, что осознанно не сделано:

1. **Rate limit только по адресу** — лимита по аккаунту на входе и суточного
   потолка приглашений на компанию нет.
2. **Ротация ключа подписи JWT** — один секрет, без `kid`.
3. **Чистка протухших сессий и старых карточек** — метод есть, воркера нет.

Подробнее — в [эксплуатации](docs/operations.md) и [безопасности](docs/security.md).
